How it works

01

Commit

Publish a binding commitment to your dataset. No rows — just a fingerprint and schema.

02

Query & prove

Run SUM / COUNT / AVG / MIN / MAX / GROUP BY. Proving happens where the data lives; only the proof bundle travels.

03

Verify

Anyone confirms the answer is bound to the published commitment — no account, no access to the data.

The zero-trust flow

GPI_ADMIN_TOKEN=secret gpi serve              # registry: multi-tenant, never sees a row
gpi create-org "Acme Health"                  # provision a tenant + API key
gpi remote-commit payroll.csv                 # commit LOCALLY, upload only the manifest
gpi remote-query <id> "SELECT SUM(salary) GROUP BY dept" --data payroll.csv
gpi share <bundle>                             # public verification link — no account, no data
