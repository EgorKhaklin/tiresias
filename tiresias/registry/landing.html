Answers about private data, with a proof

Commit a sensitive dataset, then answer aggregate questions about it. Every answer carries a proof that it is the true result over the committed rows, and the number of rows it describes. Nobody sees a row, and nobody gets an answer about too few.

Open the console Run it on your data

How it works

Commit

The data holder seals the rows into a salted SHA-256 commitment and publishes it as a manifest: the schema, the row count and a minimum cohort. No row is in it, and the commitment reveals nothing about them.

Ask

Questions are proved where the data lives, in the RISC Zero zkVM: totals, counts, averages, extremes and breakdowns. Below the minimum cohort, Tiresias declines rather than answers.

Verify

The answer travels as a proof bundle. Anyone with the link sees its receipt checked against the published commitment, with no account and no access to the data.

Who it is for

Data holders

Share statistics about records you cannot share: payroll, patients, transactions. Publish the commitment once; answer as many questions as you choose.

Analysts

Ask in plain terms or in SQL. Each answer arrives with its cohort and its proof, ready to cite, so nobody has to take the number on trust.

Auditors

Open a shared link and see the checks run, or download the proof and the manifest and verify them yourself with tiresias verify.

Run it on your data

The workbench, then the registry

The workbench runs on the machine that holds the data. Rows never leave it; commitments and proofs go to the registry, which never sees a row.

# on the data holder's machine git clone https://github.com/EgorKhaklin/tiresias && cd tiresias && pip install -e . rzup install r0vm 3.0.6 && cargo build --release --manifest-path zkvm/Cargo.toml tiresias app # commit a CSV, ask, verify: http://127.0.0.1:8765 # publishing to a registry tiresias remote-commit payroll.csv # uploads the manifest, never the rows tiresias remote-query <dataset> "SELECT SUM(salary) GROUP BY dept" --data payroll.csv tiresias share <bundle> # a public verification link
