Answers about private data, with a proof

Commit a sensitive dataset, then answer aggregate questions about it. Every answer carries a proof that it is the true result over the committed rows, and the number of rows it describes. Nobody sees a row, and nobody gets an answer about too few.

Open the console Run it on your data

How it works

Commit

The data holder fingerprints the rows into a commitment and publishes it as a manifest: the schema, the row count and a minimum cohort. No row is in it.

Ask

Questions are proved where the data lives: totals, counts, averages, extremes and breakdowns. Below the minimum cohort, Tiresias declines rather than answers.

Verify

The answer travels as a proof bundle. Anyone with the link confirms it is bound to the published commitment, with no account and no access to the data.

Who it is for

Data holders

Share statistics about records you cannot share: payroll, patients, transactions. Publish the commitment once; answer as many questions as you choose.

Analysts

Ask in plain terms or in SQL. Each answer arrives with its cohort and its proof, ready to cite, so nobody has to take the number on trust.

Auditors

Open a shared link and see the checks run: the answer, the dataset it is bound to, and the commitment that dataset published.

Run it on your data

The workbench, then the registry

The workbench runs on the machine that holds the data. Rows never leave it; commitments and proofs go to the registry, which never sees a row.

# on the data holder's machine pip install git+https://github.com/EgorKhaklin/tiresias tiresias app # commit a CSV, ask, verify: http://127.0.0.1:8765 # publishing to a registry tiresias remote-commit payroll.csv # uploads the manifest, never the rows tiresias remote-query <dataset> "SELECT SUM(salary) GROUP BY dept" --data payroll.csv tiresias share <bundle> # a public verification link

Preview: not yet for real secrets.Proofs run on Glass's research prover, over a 31-bit field with an unaudited hash, and they are not yet zero-knowledge. They demonstrate the guarantees above; they are not a vault. Tiresias moves to an audited, zero-knowledge proving system next, and this notice changes when it does.
