Tiresias interactive demo

Built on Glass
Commit a private dataset, then prove the answer to aggregate queries over it, revealing only the commitment, the query, and the answer. Never a row. Every proof below runs on the real Glass engine. crypto-grade: educational

1Commit a private dataset

The organization publishes a binding manifest: a commitment to the data plus its schema. It contains zero rows.

2Ask an aggregate question

Write SQL. The answer comes back with a zero-knowledge proof, packaged as a shareable proof bundle.

3Verify

An auditor checks the bundle. Tier 1 needs no data (binds the answer to the published commitment). Tier 2 re-runs the proof, so a wrong answer cannot pass.

4Try to cheat

Forge the answer in the bundle and verify it. The proof rejects it.

Proven today: soundness (no lying about an aggregate over committed data), privacy (answers reveal the aggregate only), binding (every answer tied to an immutable commitment). Roadmap: witness-free third-party verification, production field + audited hash, external audit. Cryptography is educational-grade by design: a working demonstration, stated on every artifact. Engine: Glass (glass.py), Pane query algebra + Frost zk-STARK.
